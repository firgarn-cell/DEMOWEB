# Портал «гражданам.егрн» — пробное демо

Пробный комплект демо по тому же паттерну, что и `korochki/` (КОД 09.02.07):
регистрация, авторизация, заявки на услуги ЕГРН, админ-панель, слайдер, мобильные макеты 390×844.

## Запуск

```bash
cd grazhdanam-egrn
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5001

На Windows: `run.bat`

## Учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Админ | `Admin` | `EgrnNET` |
| Пользователь | регистрируйте сами | ≥ 8 символов |

## Предметная область

Информационная система для граждан: заказ сведений / выписок из ЕГРН.
Пользователь подаёт заявку (вид услуги, желаемая дата получения, способ оплаты);
администратор меняет статус; после «Услуга оказана» доступен отзыв.

## Услуги (выпадающий список)

- Выписка об основных характеристиках и правах
- Выписка о кадастровой стоимости
- Выписка о переходе прав на объект

## Статусы заявки

`Новая` → `В обработке` → `Услуга оказана`
