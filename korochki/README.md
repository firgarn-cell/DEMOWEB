# Портал «Корочки.есть» — скрипт реализации ДЭ

Реализация КОД **09.02.07-3-2026** (модули 1–2 + заготовки модуля 3).

## Запуск

```bash
cd korochki
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Учётные записи

| Роль | Логин | Пароль |
|------|-------|--------|
| Админ | `Admin` | `KorokNET` |
| Пользователь | регистрируйте сами | ≥ 8 символов |

## Что реализовано

**Модуль 1**
- SQLite БД + `db/schema.sql` (для ER в СУБД)
- Регистрация с валидацией (логин, пароль, ФИО, телефон, email)
- Авторизация + сообщения об ошибках
- Ссылка «Еще не зарегистрированы? Регистрация»
- Заявки: курс, дата, оплата
- Список заявок + отзыв
- Админ-панель: смена статусов
- Хеширование паролей, сессии, роли

**Модуль 2**
- Дизайн + медиа из приложения
- Слайдер: 4 изображения, автосмена 3 сек, вперёд/назад
- Курс из `<select>`, дата `ДД.ММ.ГГГГ`
- Ошибки валидации на форме
- Отзыв только после «Обучение завершено»
- Админ: фильтр, пагинация, toast-сообщения
- Мобильные макеты 390×844 в папке `mobile/`
